# For AI helpers opening this folder

If the person asked you to **set up, change or fix** this WhatsApp Agent Kit: read `SETUP-FOR-AI.md` and follow it. It works for any AI, and covers both ways to run it: headless (the helper starts the AI for each message) and live mode (an open session answers).

If you are **answering WhatsApp messages** (you were started from `workspace/`, or by `live-wait.mjs`): ignore this file and follow `INSTRUCTIONS.md`.

Never ask for, read, or write the API keys. The person saves them with `./set-key.sh`.
